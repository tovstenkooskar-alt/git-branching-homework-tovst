#Описание проекта
Кратко: Учебный мини-проект Python («Student Branching App») для отработки процесса ветвления в Git. Ветка `master` хранит рабочую версию, а новые функции добавлялись в изолированных ветках.

#Использованные ветки
| Ветка | Что делал | Как попала в master |
|---|---|---|
| feature/profile | модуль профиля | merge локально |
| feature/subjects | список дисциплин | merge локально |
| feature/report | итоговый отчёт | Pull Request |
| experiment/broken-idea | тестовая идея | удалена без merge |

#Коммиты
Кратко перечислить 8+ основных коммитов:
1. docs: добавить README проекта
2. feat: добавить базовый запуск приложения
3. feat(profile): добавить модуль профиля студента
4. refactor(main): подключить вывод профиля
5. feat(subjects): добавить список дисциплин
6. refactor(main): подключить список дисциплин
7. feat(report): добавить генерацию итогового отчёта
8. refactor(main): подключить итоговый отчет
